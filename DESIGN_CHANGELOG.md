# Design change log

## Visual identity redesign — 2026-11-04

- Replaced the blue-heavy accents with a restrained warm palette: obsidian, ivory, sage, terracotta, lavender, champagne, and stone.
- Refined the persistent 3D hub with a ceramic and metal focal form, clearer node silhouettes, quieter connection lines, and a lower particle count.
- Applied the palette and typography across the shared shell, content pages, relationship map, cards, forms, and navigation.
- Reworked the scene exploration guide for desktop and mobile. On short viewports it collapses to a slim bar beneath the header so it no longer covers the hero copy; users can reopen it after dismissing it.
- Added a dedicated homepage profile section for GitHub and LinkedIn, sourced from the existing typed profile data.
- Added reduced-motion styling and visible keyboard focus for the new profile links.

## Scope

This change is one visual redesign pass. It preserves route content and interactions and does not change the existing project phase roadmap.
